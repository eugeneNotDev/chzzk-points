📅 방송 스케줄

🗓️
달력으로 한눈에
사이드바 방송 스케줄에서 이번 달 방송 일정을 달력으로 볼 수 있어요.
날짜를 누르면 제목과 메모가 아래에 나와요.
⏰
시작 시간 · 휴방 표시
방송 시작 시간이 날짜 칸에 바로 보이고, 쉬는 날은 🌙 휴방으로 표시돼요.
시간이 아직 안 정해진 날은 "미정"으로 나와요.

💬 자유게시판

사이드바 게시판 → 자유게시판에서 하고 싶은 이야기를 편하게 남겨보세요.

  • 익명으로 올라가요. 글과 댓글에 닉네임이 표시되지 않습니다.
  • 댓글을 달 수 있고, 사진도 최대 5장까지 올릴 수 있어요. 사진이 있는 글은 제목 옆에 사진 아이콘이 붙어요.
  • 내가 쓴 글과 댓글은 직접 수정·삭제할 수 있어요.
🤝
익명이라도 서로를 존중하는 분위기를 부탁드려요. 비방·도배 등은 운영자가 삭제할 수 있고, 반복되면 이용 제한이 있을 수 있습니다.

📝 방송 후기 — 첫 후기 +100P

사이드바 게시판 → 방송 후기에서 방송을 보고 느낀 점을 남겨주세요. 여기는 닉네임이 표시됩니다.

🎁
방송 중이거나, 방송이 끝난 지 6시간 안에 그 방송의 첫 후기를 쓰면 100P를 드려요!
항목내용
보상 시점방송 중 ~ 방송 종료 후 6시간 이내에 작성한 후기
보상 횟수방송 한 번당 1회 (후기를 여러 개 써도 중복 지급되지 않아요)
확인 방법후기 게시판 위쪽 안내 배너와 마이페이지 포인트 내역("방송 후기 보상")

📝 사용 방법

  1. 메뉴 이동 — PC는 사이드바 게시판, 모바일은 하단 더보기 → 자유게시판 / 방송 후기로 들어갑니다.
  2. 글쓰기 — 오른쪽 위 글쓰기 버튼을 누르고 제목과 내용을 적습니다. (로그인 필요)
  3. 사진 올리기 — 글쓰기 화면의 사진 버튼으로 첨부합니다. 크기는 자동으로 알맞게 줄여져요.

⚠️ 꼭 읽어주세요

📌
  • 보상을 받은 후기를 삭제하면 지급된 100P가 회수됩니다. 삭제 후 다시 써도 같은 방송으로는 보상을 다시 받을 수 없어요.
  • 포인트만을 노린 의미 없는 글·복사 글·도배는 삭제되고 보상이 회수될 수 있습니다.
  • 자유게시판은 익명이지만, 운영상 필요한 경우 운영자는 작성자를 확인할 수 있습니다.
  • 개인정보, 타인 비방, 불법·불쾌한 내용은 올리지 말아주세요.
  • 포인트는 방송용 가상 포인트이며, 현금이나 다른 재화로 바꿀 수 없습니다.
