새 기능 업데이트 — 라이트 모드
요청 주셨던 밝은 화면(라이트 모드)이 추가됐어요! 이제 취향에 맞게 어두운 화면과 밝은 화면을 골라 쓸 수 있어요.

🌗 어떤 기능인가요?

📱
기기 설정 자동 적용
폰·PC가 라이트 모드면 라이트로, 다크 모드면 다크로 알아서 시작해요.
따로 고른 적이 없다면 기기 설정이 바뀔 때도 같이 따라가요.
📌
한 번 고르면 계속 유지
직접 바꾼 테마는 새로고침하거나 다시 들어와도 그대로 유지돼요.
기기 설정이 바뀌어도 내가 고른 테마가 우선이에요.

📝 바꾸는 방법

  1. PC — 왼쪽 사이드바 맨 아래의 🌙 다크 모드 스위치를 누르면 바로 바뀌어요.
  2. 모바일 — 하단 더보기를 열면 메뉴 아래에 같은 다크 모드 스위치가 있어요.
  3. 스위치가 켜져 있으면 다크, 꺼져 있으면 라이트예요.
상황적용되는 테마
처음 접속기기 설정(라이트/다크)을 그대로 따라가요
직접 바꾼 뒤내가 고른 테마로 고정
다른 기기폰과 PC는 각각 따로 기억해요

⚠️ 참고해 주세요

📌
  • 룰렛·무료 뽑기·가위바위보·홀짝의 게임 화면은 분위기를 위해 라이트 모드에서도 어두운 무대로 유지돼요.
  • 테마 선택은 브라우저에 저장돼서, 시크릿 창이나 사이트 데이터를 지운 경우엔 다시 기기 설정으로 시작해요.
  • 라이트 모드에서 글씨가 잘 안 보이거나 어색한 곳이 있으면 알려주세요. 바로 고칠게요!
