새 기능 업데이트 — 그림 후원
이제 사이트에서 그림을 그려서 후원과 함께 보낼 수 있어요. 후원이 확인되면 내 그림이 방송 화면 위에 바로 그려져요!

✨ 어떤 기능인가요?

🖌️
방송 화면을 보면서 그리기
사이드바 그림 후원의 그림판에서 펜·지우개·색깔·굵기를 골라 그릴 수 있어요. 방송 중에는 그림판 배경에 지금 방송 화면이 보여서, 원하는 자리에 맞춰 그릴 수 있어요.
배경 버튼으로 방송 화면 / 밝은 배경 / 어두운 배경을 바꿀 수 있어요. 되돌리기(Ctrl+Z)도 되고, 그리던 그림은 창을 닫아도 남아 있어요.
📺
배경 없이 그림만 방송 위에
그림판 전체가 방송 화면 전체예요. 후원이 확인되면 배경 없이 그림만, 그린 자리 그대로 방송 화면 위에 그려지는 과정이 빠르게 재생된 뒤 10초 동안 떠 있어요.
여러 그림이 몰리면 한 장씩 차례로 나와요.

📝 사용 방법

  1. 그리기 — PC는 사이드바 그림 후원, 모바일은 하단 더보기 → 그림 후원으로 들어가 그림을 그립니다. (로그인 필요)
  2. 코드 받기 — 방송 중에 그림 보내고 코드 받기를 누르면 6자리 코드가 나와요. (예: K7Q2MX)
  3. 후원하기 — 치지직에서 후원할 때 메시지에 코드를 넣고 3,000치즈 이상 후원해요.
  4. 방송에 표시 — 후원이 확인되면 그림이 방송 화면에 그려져요. 사이트에도 방송에 나왔어요로 바뀌어요.

💡 코드는 대문자·소문자, 띄어쓰기를 신경 쓰지 않아도 돼요. 메시지에 다른 말과 같이 써도 인식돼요.

📌 규칙

항목내용
보낼 수 있는 때방송 중에만 코드를 받을 수 있어요. 그리기는 언제든 할 수 있고, 그리던 그림은 저장돼 있으니 방송이 켜지면 보내 주세요.
최소 금액한 번에 3,000치즈 이상 후원해야 떠요. 나눠서 후원한 금액은 합쳐지지 않아요.
금액이 모자라면사이트에 안내가 뜨고, 같은 코드로 다시 후원하면 그때 떠요.
코드 유효 시간코드를 받고 24시간 안에 후원해야 해요. 지나면 코드와 그림이 지워져요.
코드 개수한 사람당 하나예요. 새 코드를 받으면 아직 후원 안 한 이전 코드와 그림은 사라져요.
사용 횟수코드 하나로 그림은 한 번만 뜰 수 있어요.
보관 기간방송에 나온 그림은 내 그림에서 6개월 동안 볼 수 있어요.

💡 배경이 없어서 흰색으로 칠한 부분은 흰색 그대로 나가요. 지우고 싶은 곳은 지우개를 쓰면 투명하게 지워져요.

⚠️ 꼭 읽어주세요

📌
  • 그림은 방송 화면에 그대로 나가요. 다른 사람을 불쾌하게 하는 그림, 개인정보, 광고 등은 바로 내리고 그림 후원을 막을 수 있어요.
  • 그림이 내려가도 후원은 되돌릴 수 없어요. 보내기 전에 한 번 더 확인해 주세요.
  • 익명 후원도 코드만 맞으면 그림이 떠요. 대신 후원자 이름은 표시되지 않아요.
  • 그림 후원도 1만 치즈 이상이면 기존처럼 후원 적립(10%)이 같이 들어가요.
  • 그림판의 방송 화면 배경은 몇 초씩 늦게 바뀌어요. 방송 화면이 바뀌면 그림 위치가 어긋날 수 있어요.
  • 방송 화면이나 연결 상태에 따라 그림이 늦게 뜨거나 안 뜰 수 있어요. 이상하면 코드와 후원 시간을 같이 알려주세요.
